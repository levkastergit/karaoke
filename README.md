# Караоке — мониторинг микрофона

Небольшое приложение для Windows: выбираете микрофон, включаете режим караоке и слышите свой голос через выбранные наушники или колонки.

## Запуск

**С рабочего стола:** ярлык **«Караоке»** (без окна консоли).

1. Установите [Node.js](https://nodejs.org/) (если ещё не установлен).
2. В папке проекта выполните:

```bash
npm install
npm start
```

**PowerShell:** если появляется ошибка про `npm.ps1` и «running scripts is disabled», используйте один из вариантов:

- двойной клик по **`start.bat`** в папке проекта;
- или в терминале: `npm.cmd start` и `npm.cmd install` вместо `npm start` / `npm install`.

Пересоздать ярлык: `node create-desktop-shortcut.js` или двойной щелчок по `create-desktop-shortcut.vbs`.

3. При первом запуске разрешите доступ к микрофону.
4. Выберите микрофон и устройство вывода, нажмите **«Включить караоке»**.

## Советы

- **Используйте наушники** — иначе микрофон подхватит звук из колонок и появится эхо/свист.
- Регулируйте **усиление** ползунком (по умолчанию 150%, максимум 1000%). На высоких значениях возможны искажения — поднимайте постепенно. Если индикатор «Уровень с микрофона» почти пустой — поднимите громкость микрофона в Windows (Параметры → Звук → Ввод).
- **Шумоподавление** включено по умолчанию (встроенный фильтр браузера, не режет голос).
- **AGC** выключен по умолчанию — он удобен для тихого микрофона, но добавляет задержку.
- Для **минимальной задержки** отключите шумоподавление; в статусе показывается примерная задержка в мс.
- Кнопка ↻ обновляет список устройств, если вы подключили новый микрофон.

## Требования

- Windows 10/11
- Node.js 18+
