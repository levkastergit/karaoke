# Караоке — мониторинг микрофона

Небольшое приложение для Windows: выбираете микрофон, включаете режим караоке и слышите свой голос через выбранные наушники или колонки.

## Скачать и запустить

1. Откройте [страницу релизов](https://github.com/levkastergit/karaoke/releases/latest) и скачайте файл **`Karaoke-x.y.z.exe`**.
2. Запустите его двойным щелчком. Установка не нужна — это portable-версия, всё работает из одного файла.
3. При первом запуске разрешите доступ к микрофону.
4. Выберите микрофон и устройство вывода, нажмите **«Включить караоке»**.

> **Windows SmartScreen** может показать предупреждение «Система защитила ваш компьютер», потому что файл не подписан сертификатом.
> Нажмите **«Подробнее» → «Выполнить в любом случае»**.

## Обновление

В правом верхнем углу есть кнопка **«Обновить»**:

- при запуске программа сама тихо проверяет GitHub Releases; если вышла новая версия, кнопка подсвечивается и показывает номер версии;
- нажмите её — новая версия скачается, программа закроется, подменит свой `.exe` и запустится заново.

Если нажать кнопку, когда обновлений нет, программа просто проверит наличие новой версии ещё раз.

## Советы

- **Используйте наушники** — иначе микрофон подхватит звук из колонок и появится эхо/свист.
- Регулируйте **усиление** ползунком (по умолчанию 150%, максимум 1000%). На высоких значениях возможны искажения — поднимайте постепенно. Если индикатор «Уровень с микрофона» почти пустой — поднимите громкость микрофона в Windows (Параметры → Звук → Ввод).
- **Шумоподавление** и **AGC** добавляют задержку — отключайте их, если нужен минимальный лаг.

## Запуск из исходников (для разработки)

1. Установите [Node.js](https://nodejs.org/).
2. В папке проекта:

```bash
npm install
npm start
```

**PowerShell:** если появляется ошибка про `npm.ps1` и «running scripts is disabled», используйте `start.bat` или команды `npm.cmd install` / `npm.cmd start`.

Ярлык на рабочий стол для dev-запуска: `node create-desktop-shortcut.js` или двойной щелчок по `create-desktop-shortcut.vbs`.

## Сборка exe

```bash
npm run dist
```

Готовый файл появится в `dist/Karaoke-<версия>.exe`. Сборка — [electron-builder](https://www.electron.build/), цель `portable`.

## Как выпустить новую версию

1. Поднимите `version` в `package.json` (например, `1.2.0`).
2. Соберите: `npm run dist`.
3. Закоммитьте, создайте тег `v1.2.0` и запушьте.
4. Создайте GitHub Release для тега `v1.2.0` и прикрепите `dist/Karaoke-1.2.0.exe`.

Кнопка «Обновить» в приложении берёт последний релиз (`releases/latest`) и первый `.exe` из его файлов, поэтому важно, чтобы в релизе был ровно один `.exe`.
